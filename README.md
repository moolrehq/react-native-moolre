# react-native-moolre

This React Native plugin enables seamless integration of Moolre Payments into your React Native application.

## Installation

```sh
npm install react-native-moolre
```

## Usage


```js
import { multiply } from 'react-native-moolre';

// ...

const result = await multiply(3, 7);
```
